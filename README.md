# Make Any Room a Storefront

> No matter where you are, if you see something you like, we'll find it for you. Live.

A Meta glasses plug-in that turns whatever you're looking at into something you can shop. Walk into a room, look at a product, and get instant feedback on it — then act on it with your voice.

---

## Tracks

| Track | Sponsor |
|-------|---------|
| **Main Track** | Visa |
| **Side Track** | T-Mobile (Matchmaker) |

---

## Goal

Create a Meta glasses plug-in that allows users to walk into a room and get instant feedback on products. This includes an initial voice-driven UI that lets users:

- 🔍 **Search** for more information about a product
- 🛒 **Add to cart**
- 🔖 **Save for later**

---

## How It Works

1. **See it** — The user looks at a product through their Meta glasses.
2. **Identify it** — The glasses' camera captures the item and the plug-in recognizes the product.
3. **Hear about it** — Instant feedback is read back to the user (name, price, key details).
4. **Act on it** — The user responds by voice to search, add to cart, or save for later.

### Example voice interactions

| User says | What happens |
|-----------|--------------|
| "What is this?" | Identifies the product and gives a quick summary |
| "Tell me more" | Searches for more information (specs, reviews, other sellers) |
| "Add to cart" | Adds the product to the user's cart |
| "Save it for later" | Saves the product to the user's list |

## Sponsor Integrations

- **Visa** — Powers payment and checkout once an item is in the cart.
- **T-Mobile (Matchmaker)** — Supports the side track; matches users with the right product / seller.
